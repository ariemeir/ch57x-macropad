# Keyboards

Small auxiliary keyboards on macOS, each driven by Karabiner-Elements rules scoped to the
device, with one script per key.

| Folder | Device | What it does |
|---|---|---|
| [`ch57x-macropad/`](ch57x-macropad/) | AliExpress 3-key, 1-knob CH57x pad (1189:8890) | Flashed to emit F19-F24; knob press toggles the Elgato light |
| [`doio-macropad/`](doio-macropad/) | DOIO KB16 (d010:1601) | Stock firmware; big dial drives Elgato light2, bottom keys trigger dictation and the laser plug |
